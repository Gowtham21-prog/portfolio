# Public assets

- **Profile photo**: already set as `gowtham.png`. To replace it, drop a new
  image in here named `gowtham.png` (or upload one directly from the Hero
  section in the browser — it's saved to your browser's localStorage).
- **Resume**: add your resume as `resume.pdf` in this folder. The "Resume"
  button in the sidebar/mobile menu links to `/resume.pdf` and will start
  working automatically once the file is here.
- **Certificates**: images live in `public/certs/`. All four cards are
  wired up: `nptel-java.jpg`, `ccna-completion.jpg`, `hackindia-2026.png`,
  `oneyes-internship.png`. Click any certificate card on the site to view
  it full-size.
- **Favicon**: `favicon.svg` — feel free to swap for your own mark/logo.
